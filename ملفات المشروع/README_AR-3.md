# مشروع عُمري | My Age — Android Kotlin

هذا مشروع Android كامل قابل للاستيراد في Klencod IDE من خلال:
**استيراد مشروع من ZIP**.

## بيانات المشروع
- اسم التطبيق: عُمري | My Age
- Package / Application ID: `com.alzubair.omri`
- التقنية: Android Kotlin + WebView محلي
- أقل إصدار: Android 6.0 (API 23)
- targetSdk: 35
- صفحة التطبيق: `app/src/main/assets/index.html`

## الملفات الأساسية
- `settings.gradle.kts` و`build.gradle.kts`: إعداد Gradle الرئيسي.
- `app/build.gradle.kts`: إعداد تطبيق Android.
- `app/src/main/AndroidManifest.xml`: تعريف النشاط والصلاحيات والمستقبلات.
- `MainActivity.kt`: تشغيل الواجهة المحلية وربط JavaScript مع Android.
- `ReminderScheduler.kt`: الإشعارات والتذكيرات.
- `ReminderReceiver.kt`: استقبال موعد التذكير وإظهار الإشعار.
- `BootReceiver.kt`: إعادة جدولة التنبيهات بعد إعادة تشغيل الهاتف.
- `app/src/main/assets/index.html`: واجهة عُمري الأصلية.

## الاستيراد
1. نزّل ملف ZIP كما هو، ولا تفك ضغطه يدوياً.
2. افتح Klencod IDE.
3. اختر **استيراد مشروع من ZIP** وحدد هذا الملف.
4. انتظر حتى يقرأ ملفات المشروع ثم ابدأ البناء.

## ملاحظات مهمة
- واجهة التطبيق محفوظة محلياً داخل APK؛ لذلك لا تحتاج الإنترنت عند تشغيل التطبيق.
- فتح رابط واتساب يحتاج اتصال إنترنت.
- بناء APK عبر GitHub Actions يحتاج اتصال إنترنت.
- إشعارات Android تحتاج موافقة المستخدم على إذن الإشعارات في Android 13 وما بعده.
- جدولة التنبيهات هنا تستخدم AlarmManager غير الدقيق لتكون متوافقة مع قيود Android الحديثة؛ قد تتأخر بعض التنبيهات قليلاً بسبب وضع توفير الطاقة.
- إعداد الأعياد الهجرية موجود في واجهة HTML، لكن جدولة إشعارات الأعياد الهجرية التلقائية لم تُفعّل في هذا الإصدار.
- لم أتمكن من تنفيذ بناء Android فعلي داخل هذه البيئة؛ لذا يجب اختبار البناء داخل Klencod IDE بعد الاستيراد.
